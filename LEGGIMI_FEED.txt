MMX-Net — feed aggiornamenti
================================

URL da mettere in ac_config.json → updateFeedUrl (amici):
https://raw.githubusercontent.com/LOGANFOREWORD/MMX-NET/main/

Repo GitHub PRIVATA (raw senza token = sempre HTTP 404):
  1) Logan invita l'amico come Collaborator (Read) sulla repo del feed
  2) L'amico crea un PAT fine-grained (Contents: Read) e lo mette in
     ac_config.json → "updateFeedToken": "github_pat_…"
     (oppure env MMX_NET_UPDATE_FEED_TOKEN — mai nel repo git)
  3) Logan (DEVKIT): dopo CARICA il push è automatico se PublishTarget è il clone;
     check update riusa `gh auth token` se updateFeedToken è vuoto.

Il launcher utente all'avvio (checkUpdatesOnStart: true) mostra il popup
se ac_update_manifest.json ha Version maggiore della locale.
